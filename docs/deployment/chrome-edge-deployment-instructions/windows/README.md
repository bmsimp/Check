# Windows

Deploy Check to Chrome and Edge on Windows devices. Choose the method that matches how you manage those devices:

* **Manual deployment**: run a PowerShell script on the device, or through any tool that runs scripts
* **Domain deployment**: Intune, Group Policy, or a CIPP standard
* **RMM deployment**: step-by-step instructions for common RMMs
